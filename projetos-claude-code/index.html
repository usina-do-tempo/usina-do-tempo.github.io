Como usar

  1. Baixe o .zip e extraia.
  2. Abra a pasta do projeto no Claude Code (no app, ou no terminal: entre na pasta e digite claude).
  3. Abra o arquivo COMECE-AQUI.md da pasta e cole no Claude Code o pedido que está lá.
  4. Abra a pasta saida e confira com a lista de 60 segundos do próprio COMECE-AQUI.
  5. Para adaptar à sua rotina, edite regras/criterios.md.
Antes de usar com material de verdade
  • Material real só com autorização do seu órgão ou escritório. Processo sigiloso, ou de sigilo desconhecido, não entra.
  • Rodar no seu computador não mantém o conteúdo no computador: o texto vai para o serviço de IA. Use plano pago com o treinamento desligado.
  • O Claude Code destes projetos não entra no PJe, não abre sua caixa de e-mail e não envia nada: ele lê o que estiver em entrada e escreve em saida.
